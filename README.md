## 📌 Overview

This repository contains the source code for my personal portfolio website, live at **[prathmesh-waghmare-portfolio.onrender.com](https://prathmesh-waghmare-portfolio.onrender.com/)**. It showcases my work across deep learning, satellite imagery restoration, computer vision pipelines, and full-stack software development.

Designed with modern UI/UX principles, fast load times, responsive layouts, and interactive project cards.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React.js / Vite
* **Styling & Design:** Tailwind CSS, PostCSS
* **Icons & Animation:** Lucide Icons / Framer Motion
* **Deployment & Hosting:** [Render](https://render.com/)

---

## ✨ Key Features

* **Interactive Project Showcase:** Filter and browse projects across Computer Vision, Geospatial AI, and Full-Stack Web Development.
* **Research & Publications:** Highlights academic work, IEEE conference papers, and benchmark metrics (PSNR, SSIM).
* **Fully Responsive:** Optimized for desktop, tablet, and mobile screens.
* **Clean Performance:** Fast loading times with optimized asset delivery and zero layout shift.
* **Direct Contact:** Integrated contact section and active social links.
